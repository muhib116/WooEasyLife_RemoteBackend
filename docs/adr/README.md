# Architecture Decision Records

ADRs are the **only** path to amend Wise AI Platform Reference Architecture **1.0.0**.

Once **Accepted**, an ADR is not rewritten in place — supersede with a new ADR.

Use ADRs for:

- Ownership or boundary changes
- New published artifacts
- Merging non-Wise planes (e.g. Blog AI) into Wise
- Breaking contract evolution

Do **not** use ADRs to smuggle implementation detail that belongs under `docs/implementation/`.
