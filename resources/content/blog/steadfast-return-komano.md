রিটার্ন মানে শুধু “বিক্রি হয়নি”—মানে ডেলিভারি চার্জ, রিটার্ন চার্জ, প্যাকেজিং, অ্যাডস খরচের অংশ ও স্টাফ সময়। SteadFast ব্যবহারকারী COD সেলারদের জন্য কমানোর রাস্তা একটা টুল নয়—**চেক → কনফার্ম → বুকিং → রিটার্ন অপস** চেইন।

পিলার গাইড: [SteadFast Fraud Check Complete Guide](/steadfast-fraud-check)। সাধারণ COD প্লেবুক: [COD Return Reduction](/cod-return-reduction)।

## ধাপ ১ — পার্সেল পাঠানোর আগে ফিল্টার

অর্ডার কনফার্মের আগে মোবাইল নম্বর চেক করুন: [SteadFast Fraud Check](/steadfast-fraud-check) বা [BD Fraud Checker](/bd-fraud-checker)।

- হিস্টোরি বোঝা: [Customer History কী](/blog/steadfast-customer-history-ki)
- রেশিও বোঝা: [Delivery Ratio কী](/blog/steadfast-delivery-ratio-ki)
- কম রেট SOP: [সাকসেস রেট কম হলে](/faq/success-rate-kom-hole-ki-korbo)

কখন বাধ্যতামূলক যাচাই: [কখন কাস্টমার ভেরিফাই করব](/blog/kokhon-customer-verify-korbo)।

## ধাপ ২ — রিটার্নের কারণ আলাদা করুন

সব রিটার্ন “ফেক” নয়। ঠিকানা ভুল, impulse order, ফোন বন্ধ, এলাকা দেরি, রাইডার নোট—প্রতিটিতে আলাদা সাড়া লাগে। পিলারে সেকশন ৩ পড়ুন। প্রোডাক্ট মিসম্যাচ হলে হিস্টোরি ভালো থাকলেও রিটার্ন আসে—কনফার্ম কলে ভ্যারিয়েন্ট আবার বলুন।

## ধাপ ৩ — প্রোটেকশন লেয়ার

শুধু একবার চেক করে থেমে গেলে একই নম্বর ফিরে আসে।

- Checkout OTP: [OTP কখন](/faq/cod-order-otp-kokhon)
- Duplicate block: [ডুপ্লিকেট COD ব্লক](/faq/duplicate-cod-order-block)
- Blacklist: [কাস্টমার ব্ল্যাকলিস্ট](/faq/woocommerce-customer-blacklist) · [রিটার্নের পর ব্ল্যাকলিস্ট](/blog/blacklist-customer-after-returns)
- সব একসাথে: [ফেক অর্ডার প্রোটেকশন](/fake-order-protection)

## ধাপ ৪ — কনফার্মের পর বুকিং ভুল কমান

ম্যানুয়াল SteadFast প্যানেলে কপি-পেস্টে টাইপো ও ভুল জোন রিটার্ন বাড়ায়। কনফার্মড অর্ডারে [কুরিয়ার অটো এন্ট্রি](/courier-auto-entry) ও [SteadFast ইন্টিগ্রেশন](/steadfast-integration) ব্যবহার করুন।

## ধাপ ৫ — বুকিংয়ের পর Return Hub

রাইডার cancel বা return request এলে পোর্টালে প্রতিবার Change Status না ঘুরে [SteadFast Return Hub](/steadfast-return-hub) থেকে Decide করুন—Confirm cancel বা Ask to resend, প্রয়োজনে রাইডার কল। Stuck স্ক্যান সাপ্তাহিক রাখুন।

## ধাপ ৬ — মাসিক লস মাপুন

রিটার্ন রেট না জানলে অ্যাড বাজেট বাড়ানো জুয়া। [রিটার্ন লস ক্যালকুলেটর](/return-loss-calculator) চালান। উদাহরণ কেস: [SteadFast Fraud Check কেস স্টাডি](/blog/steadfast-fraud-check-case-study)।

ধরুন মাসে ৬০০ অর্ডার, রিটার্ন ১৮% → ১০৮ রিটার্ন। প্রতি রিটার্নে গড়ে ২৫০ টাকা লস হলে ≈ ২৭,০০০ টাকা/মাস। ১৮% থেকে ১২%-এ নামালেই বড় সেভ।

## যা করবেন না

অন্ধভাবে পার্সেল পাঠানো, শুধু ফোন কনফার্মে নির্ভর, টুলকে গ্যারান্টি ভাবা, স্টাফকে শুধু “পার্সেল পাঠাও” টার্গেট দেওয়া। বিস্তারিত: [Common mistakes](/blog/steadfast-fraud-check-common-mistakes)।
